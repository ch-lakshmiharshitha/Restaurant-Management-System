# Restaurant Management System 🍴

Welcome to the **Restaurant Management System**, a web-based application designed to simplify restaurant operations and enhance the customer dining experience. The platform provides seamless menu browsing, cart management, user authentication, and order processing through an intuitive interface.

## 🚀 Features

### 🛒 Customer Side

* Menu Browsing – Explore a variety of food items and categories.
* Cart Management – Add, update, and remove items from the cart.
* User Authentication – Secure user registration and login.
* Order Placement – Place food orders efficiently.
* Customer Profile Management – Manage user information and account details.

### 🏢 Restaurant Side

* Menu Management – Store and manage food items using MySQL.
* Order Processing – Handle customer orders efficiently.
* Customer Data Management – Maintain customer records securely.
* Database-Driven Operations – Seamless integration with MySQL for data storage and retrieval.

## 🛠 Tech Stack

**Frontend:** HTML, CSS, JavaScript, EJS

**Backend:** Node.js, Express.js

**Database:** MySQL

**Tools:** Git, GitHub, VS Code

## 📂 Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/ch-lakshmiharshitha/Restaurant-Management-System.git
cd Restaurant-Management-System
```

### Install Dependencies

```bash
npm install
```

### Configure Database

* Create a MySQL database.
* Import the required tables.
* Update database credentials in the project configuration files.

### Start the Application

```bash
npm start
```

### Open in Browser

```text
http://localhost:8080
```
